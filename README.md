# JellyELEC

A Jellyfin-first client for CoreELEC. JellyELEC draws its own full-screen interface and uses Kodi only as the playback engine, so Dolby Vision (including FEL) plays exactly as it does in CoreELEC.

**Status:** early development. Not ready for everyday use.

## Version 1 goals

1. Log in and pick a server, with auto-discovery on the local network
2. Home screen: Continue Watching, Next Up, and Latest rows for each library
3. Movie and show detail pages with a Special Features row
4. Direct play only, with watch progress reported back to Jellyfin
5. Live TV tab that opens the IPTV Simple Client guide
6. Boots straight into JellyELEC and reopens it if it closes
7. Fully controllable with standard Kodi remote actions, so Unfolded Circle remotes work through the existing Kodi integration
